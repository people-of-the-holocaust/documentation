\section{Overall Description}

\subsection{Product Perspective}
The system has three main parts: a frontend website, a database, and a backend interpreter. The frontend gives the public a user interface. The database stores structured people, places, activities, and location records. The interpreter processes encyclopedia text and prepares records for storage in the database.

\subsection{Product Functions}

\begin{enumerate}
	\item Display a public homepage explaining the purpose behind the project.
	\item Allow users to search and browse people records.
	\item Allow users to search and browse place records.
	\item Display historical locations on an interactive map.
	\item Store structured data in a database.
	\item Process source material into structured records.
\end{enumerate}

\subsection{User Classes}

\begin{enumerate}
	\item Researchers and academics using the system for historical research.
	\item Students using the system for learning and class projects.
	\item General public users interested in the history behind the Holocaust.
	\item Project maintainers responsible for the frontend, database, and interpreter.
\end{enumerate}
